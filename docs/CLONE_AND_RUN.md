# Клон репозитория → готовый кабинет

## Что воспроизводится

Исходники интерфейса и сервера, пять видов продуктов, заявки с состояниями,
документы и история операций. В `contracts/demo/` сохранён согласованный SQLite-снимок
демо-кабинета на 25.10.2026: 13 заявок, диалог с Лумой, счёт PDF
и четыре оплаты поставщикам. На расчётном счёте — **1 359 976,99 ₽** для новых
операций. Снимок проходит проверку SHA-256 и целостности SQLite.
API-ключей в нём нет. Он применяется только к пустому выделенному тому.

В «Моём финансировании» действуют все пять продуктов. В истории есть закрытый
кредит, погашенный рефинансированием кредит, выборка и возврат денег по линии,
использование и автоматическое погашение овердрафта. Среди заявок — черновики,
запрос дополнительных сведений, готовые предложения, договор к подписанию и
отменённый проект. Календарь содержит 111 событий, включая поступления и списания.
Случайных тестовых заявок в сдаваемом снимке нет.

Снимок можно пересобрать отдельно от работающего кабинета:
`uv run --frozen python -m scripts.build_submission_snapshot --date 2026-10-25`.
Команда использует обычные сервисы оформления и операций; правила скоринга и
ограничения продуктов сохраняются. Новые запросы оцениваются по этим правилам.

Остатки, даты и история начинаются с сохранённого состояния. Затем сервер работает
по текущему времени: проценты начисляются и запланированные платежи исполняются
по обычным правилам. Новые ответы LLM не обязаны дословно повторяться.
Тема, выбранная вкладка и другие настройки браузера сохраняются отдельно на каждом устройстве.

## Быстрый запуск

Установите Git, Docker с Compose v2 и Python 3.11+:

```shell
git clone https://github.com/xMewrizz/delo-za-malym.git
cd delo-za-malym
python -m scripts.start_hackathon
```

Первый запуск спрашивает ключ Dahl скрытым вводом и записывает его только в
локальный `.env.api`. Запускать `uv`, устанавливать Node/Python-зависимости
или скачивать Gemma не нужно: зависимости приложения устанавливаются внутри Docker.
Нужен интернет для первого скачивания базовых образов, зависимостей и вызовов Dahl.

Главная: **http://localhost:18007/**. Кабинет: **http://localhost:18007/cabinet?mode=business**.

В `api` работают `CHAT_MODE=model`, URL `https://inference.dahl.global/v1`,
модель `MiniMaxAI/MiniMax-M2.7`, формат `json_object`, тайм-аут 120 секунд,
контекст 16 384 и ответ до 4096 токенов. Это параметры проверенного локального API-стенда.
Ollama и локальные веса не запускаются. Доступность и квота Dahl зависят от переданного ключа.

## Вариант только с Docker

Скопируйте `.env.api.example` в `.env.api`, заполните `LLM_API_KEY` ключом,
который команда передала отдельно. Затем из корня репозитория:

```shell
docker compose --env-file .env.api -p alfa-hackathon -f compose.demo.yaml -f compose.api.yaml -f compose.hackathon.yaml up --build -d --wait api
```

В PowerShell копирование: `Copy-Item .env.api.example .env.api`.
В Linux/macOS: `cp .env.api.example .env.api`.
Файл `.env.api` исключён из Git и Docker build context; ключ получает сервер,
а не браузер. Не публикуйте вывод `docker compose config`: он раскрывает значения окружения.

## Проверка без ИИ

```shell
python -m scripts.start_hackathon --without-ai
```

Команда не читает `.env.api`, не просит ключ, не запускает модель и не скачивает
её веса. Подбор через формы, проверки, скоринг, решение, подписание и обслуживание
работают на том же кредитном движке. Лума показывает только фиксированные
демо-примеры. Для отдельного тома: `--project alfa-jury`.

Вариант без Python на хосте:

```shell
docker compose --env-file .env.example -p alfa-jury -f compose.demo.yaml -f compose.hackathon.yaml up --build -d --wait api
```

Для этого варианта не задавайте `DEMO_CHAT_MODE=model` в окружении терминала.

## Свой API или модель вне Docker

В `.env.api` замените три значения:

```dotenv
LLM_API_BASE_URL=http://host.docker.internal:11434/v1
LLM_MODEL=имя-вашей-модели
LLM_API_KEY=
LLM_RESPONSE_FORMAT=json_schema
```

Это пример адреса модели на компьютере, где запущен Docker. Для удалённого сервера
укажите его URL и ключ; для сервера без авторизации ключ оставьте пустым.
`localhost` внутри контейнера относится к самому контейнеру, поэтому для сервера
на хосте используется `host.docker.internal`. Настройте модель на прослушивание
адреса, доступного Docker, и проверьте локальный firewall.

```shell
python -m scripts.start_hackathon --env-file .env.api
docker compose --env-file .env.api -p alfa-hackathon -f compose.demo.yaml -f compose.api.yaml -f compose.hackathon.yaml exec -T api python -m scripts.check_llm --generate
```

Последняя команда отправляет один синтетический запрос и проверяет формат ответа.
Для API без JSON Schema выберите `LLM_RESPONSE_FORMAT=json_object`; если модель
не поддерживает инструменты, укажите `AGENT_TOOLS_ENABLED=false` в `.env.api`. Локальная Gemma в Docker имеет
готовый профиль в [LLM_MODES.md](LLM_MODES.md).

| Переменная | Назначение / стандартный API-профиль |
|---|---|
| `LLM_API_BASE_URL` | OpenAI-совместимый URL с `/v1`; по умолчанию Dahl |
| `LLM_MODEL` | Точный ID модели; `MiniMaxAI/MiniMax-M2.7` |
| `LLM_API_KEY` | Ключ backend; пустой для сервера без авторизации |
| `LLM_RESPONSE_FORMAT` | `json_object` либо `json_schema` |
| `HTTP_TIMEOUT_SECONDS` | Тайм-аут API; 120 секунд |
| `LLM_CONTEXT_SIZE` / `LLM_MAX_OUTPUT_TOKENS` | Контекст / ответ; 16 384 / 4096 |
| `LLM_TEMPERATURE` / `LLM_TOP_P` | Параметры генерации; 0.1 / 0.9 |
| `DEMO_PORT` | Порт при прямом Compose-запуске; 18007 |

`.env.api.example` содержит готовые значения Dahl. Доступность и скорость API
зависят от провайдера. Подробнее о модели и лицензии — [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md).

## Повторный запуск и остановка

Повторите команду запуска: существующие записи сохранятся. Занятый порт можно
поменять через `--port 18009`; отдельную копию данных — через `--project alfa-review`.

```shell
docker compose --env-file .env.api -p alfa-hackathon -f compose.demo.yaml -f compose.api.yaml -f compose.hackathon.yaml down
```

Остановка без `-v` сохраняет том. Запуск с новым именем проекта создаёт новую
независимую копию снимка. Рабочие стенды `alfa_hack` и `alfa-showcase` команда не изменяет.

## Проверка

Откройте `/health`, затем проверьте «Моё финансирование», календарь и заявки.
В «Получить финансирование → С Лумой» начните новый разговор и отправьте вопрос.
При неверном ключе или недоступном API сервер покажет ошибку, а не подменит ответ
фиксированным демо-сценарием. Swagger доступен по `/docs`.

## Локальная модель и VPS

Этот быстрый профиль использует API. Локальная Gemma остаётся отдельным
режимом с собственным скачиванием весов: [LLM_MODES.md](LLM_MODES.md).
Для публикации на VPS используйте [состав с API и прокси](technical/DEPLOYMENT.md).
