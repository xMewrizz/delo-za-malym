# Клон репозитория → готовый кабинет

## Что воспроизводится

Исходники интерфейса и сервера, пять видов продуктов, заявки с состояниями,
документы и история операций. В `contracts/demo/` сохранён согласованный SQLite-снимок
локального демо-кабинета на 25.10.2026: 13 заявок, два диалога, два документа
и две оплаты поставщикам. Снимок проходит проверку SHA-256 и целостности SQLite.
API-ключей в нём нет. Он применяется только к пустому выделенному тому.

Остатки, даты и история начинаются с сохранённого состояния. Затем сервер работает
по текущему времени: проценты начисляются и запланированные платежи исполняются
по обычным правилам. Новые ответы LLM не обязаны дословно повторяться.
Тема, выбранная вкладка и другие настройки браузера сохраняются отдельно на каждом устройстве.

## Быстрый запуск

Установите Git, Docker с Compose v2 и Python 3.11+:

```shell
git clone https://github.com/xMewrizz/delo-za-malym.git
cd delo-za-malym
python -m scripts.start_hackathon
```

Первый запуск спрашивает ключ Dahl скрытым вводом и записывает его только в
локальный `.env.api`. Запускать `uv`, устанавливать Node/Python-зависимости
или скачивать Gemma не нужно: зависимости приложения устанавливаются внутри Docker.
Нужен интернет для первого скачивания базовых образов, зависимостей и вызовов Dahl.

Главная: **http://localhost:18007/**. Кабинет: **http://localhost:18007/cabinet?mode=business**.

В `api` работают `CHAT_MODE=model`, URL `https://inference.dahl.global/v1`,
модель `MiniMaxAI/MiniMax-M2.7`, формат `json_object`, тайм-аут 120 секунд,
контекст 16 384 и ответ до 4096 токенов. Это параметры проверенного локального API-стенда.
Ollama и локальные веса не запускаются. Доступность и квота Dahl зависят от переданного ключа.

## Вариант только с Docker

Скопируйте `.env.api.example` в `.env.api`, заполните `LLM_API_KEY` ключом,
который команда передала отдельно. Затем из корня репозитория:

```shell
docker compose --env-file .env.api -p alfa-hackathon -f compose.demo.yaml -f compose.api.yaml -f compose.hackathon.yaml up --build -d --wait api
```

В PowerShell копирование: `Copy-Item .env.api.example .env.api`.
В Linux/macOS: `cp .env.api.example .env.api`.
Файл `.env.api` исключён из Git и Docker build context; ключ получает сервер,
а не браузер. Не публикуйте вывод `docker compose config`: он раскрывает значения окружения.

## Повторный запуск и остановка

Повторите команду запуска: существующие записи сохранятся. Занятый порт можно
поменять через `--port 18009`; отдельную копию данных — через `--project alfa-review`.

```shell
docker compose --env-file .env.api -p alfa-hackathon -f compose.demo.yaml -f compose.api.yaml -f compose.hackathon.yaml down
```

Остановка без `-v` сохраняет том. Запуск с новым именем проекта создаёт новую
независимую копию снимка. Рабочие стенды `alfa_hack` и `alfa-showcase` команда не изменяет.

## Проверка

Откройте `/health`, затем проверьте «Моё финансирование», календарь и заявки.
В «Получить финансирование → С Лумой» начните новый разговор и отправьте вопрос.
При неверном ключе или недоступном API сервер покажет ошибку, а не подменит ответ
фиксированным демо-сценарием. Swagger доступен по `/docs`.

## Локальная модель и VPS

Этот быстрый профиль использует API. Локальная Gemma остаётся отдельным
режимом с собственным скачиванием весов: [LLM_MODES.md](LLM_MODES.md).
Для VPS описан состав с API и прокси; реальный VPS этим запуском не развёртывается.
