# Фронтенд «Дело за малым»

React, TypeScript и Vite. Главная `/` — обзорный лендинг; `/project` — описание проекта; `/documentation` — руководство и документация; `/cabinet` — рабочий кабинет:

- **Обзор** — остаток, ближайший платёж и текущие заявки.
- **Данные бизнеса** — профиль и финансовая история из API.
- **Получить финансирование** — самостоятельный подбор и **С ИИ-ассистентом**. У способов независимые черновики, уточнения и расчёты.
- **Заявки** — выбранные условия, отправка, проверки, поручительство и оформление.
- **Моё финансирование** — действующие кредиты и полученные продукты.
- **Платёжный календарь** — все продукты или один выбранный кредит/лимит.

Данные читаются из FastAPI. Черновики ручного подбора и ассистента независимы; профиль банка и список оформляемых заявок общие.

## Запуск

Из корня репозитория:

```sh
docker compose up --build -d
```

Главная: http://localhost:8000/, кабинет: http://localhost:8000/cabinet.
Порт можно изменить через `API_PORT` в корневом `.env`. Docker собирает React и раздаёт его вместе с API; Node.js в готовом контейнере не нужен. Тестовый чат остаётся на `/chat`.

Для разработки нужны Node.js 24+ и работающий backend:

```sh
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/cabinet. Vite проксирует `/api` на http://127.0.0.1:8000.
Другой адрес задаётся через `BACKEND_URL` в `.env.local` по образцу `.env.example`.
`VITE_API_BASE_URL` по умолчанию равен `/api`; ключи модели хранятся только в корневом `.env` и используются backend.

```sh
npm run check       # TypeScript, линтер и модульные тесты
npm run build       # production-сборка в dist/
```

Для интеграционных тестов из корня репозитория:

```sh
uv run --frozen python -m scripts.run_frontend_checks
```

Команда поднимает настоящий API с временной базой и демонстрационным ассистентом. Проверяет 14 сценариев рассмотрения, контракт диалога и полный путь через компоненты React: подбор, оформление, карточки уточнений, график, независимость черновиков и восстановление ввода. Внешняя модель не вызывается, рабочая база не меняется.

## Исходники

- `src/pages/cabinet-page.tsx` — разделы кабинета и отдельные черновики.
- `src/features/applications` — формы, сравнение, денежный план и оформление.
- `src/features/assistant` — диалог, карточки уточнений, предложенные данные и предпросмотр.
- `src/features/products` — каталог из API.
- `src/shared/api/client.ts` — запросы, таймауты и проверка ответов.
- `src/styles/tokens.css`, `src/shared/ui` — тема и общие компоненты.
