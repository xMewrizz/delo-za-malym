# Шаблон функции фронтенда

## Сценарий

Опишите одно действие клиента: откуда он приходит, что вводит или выбирает и что
должен увидеть после ответа сервера.

## Данные и API

- Методы и тела запросов: сверить с `docs/technical/BACKEND.md` и текущей схемой
  `/openapi.json` работающего backend.
- Какие поля ответа показываются и какие сохраняются в query cache.
- Какие значения пользователь подтверждает явно; для изменения заявки указать
  `base_application_version` и поведение при HTTP 409.

## Состояния экрана

Загрузка, данные, пустой результат, ошибка, повтор запроса и состояние во время
действия. Для финансовых сумм использовать строки из API без расчёта в браузере.

## Критерии готовности

- Клиент завершает сценарий и может продолжить его после обновления страницы.
- Данные и разрешённые действия совпадают с ответом backend.
- На мобильной ширине доступны все поля и кнопки; у полей есть подписи, действие
  доступно с клавиатуры.
- `npm run check` и `npm run build` проходят; интерфейс проверен в браузере.
