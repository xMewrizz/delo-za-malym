# Демонстрационный кабинет

ООО «Север» — синтетическая компания с историей использования кабинета. При первом запуске в новый Docker-том загружается снимок из `contracts/demo/`. Повторный запуск сохраняет пользовательские изменения.

```shell
python -m scripts.start_hackathon
```

Откройте **http://localhost:18007/cabinet?mode=overview**. Настройки Dahl, режим без модели и подключение собственного API описаны в [инструкции запуска](CLONE_AND_RUN.md).

## Данные

- 11 заявок: запрос сведений, готовые предложения, договор к подписанию, оформленные и отменённые заявки. Тестовых черновиков нет.
- Пять действующих продуктов, полностью погашенный кредит и кредит, закрытый рефинансированием.
- 1 359 976,99 ₽ на расчётном счёте для новых операций.
- История поступлений, четыре оплаты поставщикам, выборки и погашения по линии, использование и автопогашение овердрафта.
- PDF-счёт с распознанными данными. Лума начинает новый диалог через настроенный API.

Снимок подготовлен на 26.10.2026. Начисление процентов и исполнение запланированных платежей продолжаются по текущему времени сервера.

## Продукты

| Продукт | Состояние примера |
|---|---|
| Оборотный кредит | Часть долга погашена, будущие платежи доступны в графике |
| Инвестиционный кредит | Собственный взнос 20%, отсрочка основного долга на три месяца |
| Рефинансирование | Прежний кредит закрыт, обязательство учитывается в новом графике |
| Возобновляемая линия | Выполнены выборка, оплата процентов и частичное погашение |
| Овердрафт | Недостающие 35 000 ₽ использованы при оплате; выручка погасила долг и проценты |

Новые запросы проходят обычные проверки и ограничения продуктов. Масштаб банковской истории `DEMO_BUSINESS_SCALE=6` сохраняет сезонность и отрицательные месяцы, оставляя возможность подбирать новое финансирование поверх действующего портфеля.

## Отдельная копия

```shell
python -m scripts.start_hackathon --project alfa-demo-new --port 18009
```

Новое имя проекта создаёт независимый том. Существующая база не заменяется.

Для пересборки исходного снимка из синтетической истории:

```shell
uv run --frozen python -m scripts.build_submission_snapshot --date 2026-10-26
```

Команда создаёт снимок и манифест в `contracts/demo/`, используя штатные сервисы выдачи, платежей и погашения. Рабочие Docker-тома она не изменяет.
