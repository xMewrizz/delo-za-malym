# Фронтенд

`frontend/` — React + TypeScript + Vite. Главная `/` показывает каталог; `/cabinet` содержит самостоятельный подбор, подбор с ассистентом и заявки. Docker собирает статические файлы и FastAPI раздаёт их с того же адреса, что и `/api`. Тестовый чат `/chat` сохранён отдельно.

## Модули

- `app` — маршруты, провайдеры и оболочка.
- `pages` — сборка экранов и координация функций.
- `features/products` — каталог.
- `features/applications` — данные бизнеса, потребность, сравнение, план и оформление.
- `features/assistant` — сообщения, уточнения, изменения из разговора и предпросмотр.
- `shared` — HTTP-клиент, форматирование и общие элементы интерфейса.

Серверные данные находятся в TanStack Query, ответы проверяются через Zod. Расчёты и решение выполняются на backend; суммы передаются десятичными строками.

## Черновики и подтверждение

Самостоятельный подбор и ассистент создают разные заявки. Их идентификаторы и несохранённый ввод восстанавливаются из локального хранилища. Подтверждённые данные, история диалога и этапы заявки сохраняются на сервере.

Предложение ассистента отображается в рабочей области сразу после ответа. `/proposals/{id}/preview` считает его на копии; приложение не меняется до подтверждения. Карточки уточнений приходят из API и отвечают через `/clarifications/{id}/answer`, без дополнительного вызова модели.

После подтверждения данных сервер создаёт варианты. Выбор через `/explorations/{id}/apply` переводит пользователя в «Заявки»; отправка требует отдельного подтверждения. Предварительные варианты не подменяют итоговое банковское решение.

Мутации передают версии заявки и диалога. При 409 загружаются актуальные данные; действие автоматически не повторяется. Поздний ответ ассистента обновляет только его черновик.

## Оформление и запуск

Тема задана в `src/styles/tokens.css`, общие элементы — в `src/shared/ui`. Manrope и JetBrains Mono поставляются локально, лицензии находятся в `frontend/licenses`. Интерфейс предусматривает мобильную компоновку и `prefers-reduced-motion`.
