Основные тесты, из корня:

```shell
uv sync --frozen
uv run --frozen python -m unittest discover -s tests
npm --prefix frontend ci
npm --prefix frontend run check
uv run --frozen python -m scripts.run_frontend_checks
```

Повтор диалоговой проверки с настроенным API (расходует квоту):

```shell
uv run --frozen python -m scripts.run_dialogue_evaluation --env-file .env.api --cases contracts/evals/luma-regression-cases.json --trials 3 --workers 2 --output reports/luma-regression.json
```

Тесты создают синтетические заявки. Используйте штатный раннер с временными базами,
а не адрес демонстрационного кабинета. Набор регрессии включает вопросы, которые
обрабатываются кодом без генерации; 60/60 не является метрикой качества модели
на произвольных диалогах. После этой серии добавлялись проверки формата ответа,
покрытые модульными тестами. Gemma в новом окружении требует отдельной приёмки:
[инструкция](LLM_MODES.md).

Остаются предупреждение сборки о JS-чанке кабинета более 500 kB и зависимость
свободного диалога от задержки/доступности инференса. Ручной кредитный путь
работает независимо от модели.
