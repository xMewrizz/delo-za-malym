# Рефинансирование

Новый кредит полностью погашает выбранные действующие кредиты. Деньги направляются на закрытие долгов; дополнительная сумма на счёт не поступает.

## Путь клиента

1. В самостоятельном подборе выбрать «Объединить кредиты» либо рассказать об этой задаче ассистенту.
2. Отметить кредиты из банковского профиля. Остатки долга, платежи и графики уже известны; вручную их вводить не нужно.
3. Сравнить текущие обязательства с несколькими сроками нового кредита: платёж, все оставшиеся выплаты, разница и графики по датам.
4. Выбрать условия, проверить заявку и отправить её. После рассмотрения выбрать предложение, выполнить условия при их наличии и подтвердить подписание.
5. Симулятор закрывает выбранные обязательства и создаёт новый кредит. Календарь и следующие заявки учитывают замену.

Снижение платежа и снижение стоимости показаны отдельно. Например, при долге 700 000 ₽ и оставшихся выплатах 805 000 ₽ короткий новый кредит может сократить стоимость, но увеличить платёж. Более длинный срок может снизить платёж, увеличив общую сумму выплат. Такой вариант прямо помечается.

## Данные и расчёт

В заявке:

```json
{
  "need": {"purpose": "refinancing", "preferred_product": "refinancing"},
  "product_details": {"refinancing": {"loan_ids": ["existing-001"]}}
}
```

Сервер сам определяет `need.requested_amount` как сумму остатков выбранных долгов. Выбор содержит только идентификаторы; банковские суммы и графики защищены от редактирования.

`credit_engine.refinancing.assess_refinancing` проверяет возможность погашать новый кредит с учётом остальных обязательств. Выбранные долги исключаются только из расчётной копии нагрузки; до подписания они остаются действующими. Частичное погашение выбранного набора и дополнительная выдача не предусмотрены.

`POST /api/applications/{id}/explorations` с `product_id: "refinancing"` возвращает варианты на 6, 12, 18, 24, 36 и 48 месяцев, прошедшие проверку доступного платежа. Можно ограничить срок и максимальный платёж. Демонстрационная ставка — 20% годовых, комиссия за выдачу и досрочное погашение — 0 ₽.

В `result.refinancing` и `option.refinancing`:

- `payoff_amount` — сумма закрываемого основного долга;
- `current_monthly_payment` — суммарный текущий месячный платёж;
- `current_total_repayment` — все оставшиеся выплаты по выбранным графикам;
- `monthly_payment_reduction` — на сколько новый платёж ниже текущего; отрицательное значение означает рост;
- `total_cost_change` — новые общие выплаты минус прежние оставшиеся; положительное значение означает удорожание;
- `loans` — выбранные обязательства с оставшимися графиками.

Уже уплаченные проценты в сравнение не входят. Если банковского остатка или графика недостаточно, система запрашивает уточнение и не показывает придуманную экономию.

## Завершение и календарь

Подписание повторно проверяет выбранные долги и сумму их погашения. Закрытие и создание нового обязательства сохраняются одной транзакцией. Повторный запрос подписи не создаёт второй кредит. Если другой заявкой долг уже закрыт, старое предложение требует пересчёта.

В `completion` сохраняются `product_id: "refinancing"`, `repaid_loans`, `cash_to_client: "0.00"`, `settlement_type: "direct_loan_repayment"` и новый датированный `schedule`.

Прежние заявки и их отправленные версии остаются в истории. В портфеле заменённый кредит помечается погашенным рефинансированием; его будущие платежи убираются. В календаре появляются закрытие старых долгов и график нового кредита. Остаток денег не увеличивается; деньги, полученные по прежнему кредиту ранее, повторно не списываются.

Проверки: `uv run --frozen python -m unittest tests.test_refinancing -v`. Сквозной путь интерфейса входит в `uv run --frozen python -m scripts.run_frontend_checks`.
