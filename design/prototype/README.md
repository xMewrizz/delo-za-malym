# Прототип кредитного кабинета

Интерактивный референс для дизайнера: расположение блоков, два входа в заявку, подтверждение сведений, предложения и состояния рассмотрения. Визуальные детали и окончательное оформление определяет дизайнер.

## Просмотр

Скачайте репозиторий и откройте [index.html](index.html) обычным браузером. Установка зависимостей, запуск сервера и подключение к интернету не требуются. Веб-интерфейс GitHub показывает исходный код файла.

Для просмотра пути клиента выберите задачу или продукт и заполните сумму либо примените пример помощника. После перехода к данным бизнеса кнопка «Открыть пример финансов» загружает фиксированный сценарий. Подтвердите сведения, выберите предложение и отправьте демонстрационную заявку. Этапы рассмотрения переключаются кнопками; после итогового выбора доступна «Новая потребность».

Состояние сохраняется локально, если браузер разрешает локальное хранилище. Переименование файла или перенос на другой адрес может открыть новый просмотр.

## Содержание

- `index.html` — автономная версия для просмотра; стили и сценарии включены в файл.
- `cabinet.fragment.html` — редактируемый исходник макета без оболочки автономного просмотра.

«Подобрать под задачу» начинается с бизнес-ситуации. «Я знаю продукт» открывает каталог и параметры выбранной механики. Помощник показывает заранее подготовленные примеры; применение значений требует подтверждения. Сценарий «а если» остаётся отдельным до применения к черновику.

Полный путь показан на вымышленном ООО «Север»: миллион рублей на закупку, исходный срок 12 месяцев, доступный платёж 70 000 ₽. Для 18 и 24 месяцев показаны значения из кредитного калькулятора при демонстрационной ставке 24% годовых. Для остальных продуктов показана структура формы.

Референс не подключён к backend, LLM или модулю рассмотрения, не загружает реальные документы и не отправляет заявку в банк. Подписание и выдача не выполняются.

Продуктовые правила: [форма клиента](../../docs/technical/CLIENT_FORM.md) и [путь клиента](../../docs/technical/CLIENT_JOURNEY.md).
