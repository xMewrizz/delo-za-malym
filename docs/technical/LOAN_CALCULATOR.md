# Кредитный калькулятор

Модуль: [credit_engine/loans.py](../../credit_engine/loans.py). Рассчитывает аннуитетный график разового кредита с фиксированной ставкой и ежемесячными платежами. Зависимости — стандартная библиотека Python.

## 1. Вызов

```python
from credit_engine import calculate_loan

result = calculate_loan(
    amount="1000000.00",
    term_months=18,
    annual_rate_percent="24.00",
)
payload = result.to_dict()
```

| Параметр | Формат |
|---|---|
| `amount` | Положительная сумма в рублях, строка с двумя знаками после точки |
| `term_months` | Целое число от 1 до 600; 600 — технический предел горизонта расчёта |
| `annual_rate_percent` | Неотрицательная ставка в процентах годовых, строка с двумя знаками после точки |

Ставка `"24.00"` означает 24% годовых. Нулевая ставка допустима. Калькулятор проверяет формат и вычисляет график; допустимые суммы, сроки и ставки конкретного продукта проверяются отдельно.

## 2. Результат

Результат содержит `status`, `calculation` и `issues`:

- `calculated` — график рассчитан, `issues` пустой.
- `needs_information` — обязательное значение равно `None`.
- `invalid_data` — нарушен формат, диапазон или тип значения.

При ошибке `calculation = null`. Каждая ошибка содержит `field`, `code`, `message`. Если одновременно есть ошибки формата и пропуски, статус — `invalid_data`, а `issues` содержит все ошибки.

| Поле `calculation` | Смысл |
|---|---|
| `amount`, `term_months`, `annual_rate_percent` | Исходные параметры |
| `monthly_payment` | Регулярный аннуитетный платёж, округлённый до копеек |
| `maximum_payment` | Максимальный фактический платёж во всём графике |
| `total_interest` | Сумма начисленных процентов |
| `fees_total` | Комиссии, фиксированно `0.00` |
| `total_repayment` | Сумма всех платежей: основной долг и проценты |
| `schedule` | График из `term_months` записей |

Запись графика содержит `month_number` (от 1), `opening_balance`, `principal_payment`, `interest_payment`, `total_payment`, `closing_balance`. Это номера платёжных периодов без календарных дат.

В Python денежные значения и ставка имеют тип `Decimal`; `to_dict()` переводит их в строки с двумя знаками после точки, а график — в список объектов. Результат калькулятора внутренний и не изменяет публичный контракт `offer` версии `0.1`.

## 3. Расчёт и округление

Месячная ставка равна годовой ставке, делённой на 100 и 12. Формула аннуитета определена в [спецификации продукта](FIRST_PRODUCT.md#5-расчёт-графика-и-стоимости). При нулевой ставке регулярный платёж равен сумме кредита, делённой на срок.

Регулярный платёж и проценты каждого периода округляются до копеек по `ROUND_HALF_UP`. Проценты начисляются на остаток основного долга. Последний платёж закрывает остаток; общие выплаты рассчитываются суммированием графика. Платёж ограничен остатком долга с процентами, чтобы округление малых сумм не создавало переплату или отрицательный остаток.

Комиссии, дневные начисления, просрочка и досрочное погашение в эту модель не входят. Калькулятор не принимает кредитное решение и не выполняет скоринг.

## 4. Контрольный пример и проверка нагрузки

Для 1 000 000 ₽ на 18 месяцев под 24%:

| Показатель | Значение |
|---|---:|
| Регулярный платёж | 66 702,10 ₽ |
| Последний и максимальный платёж | 66 702,18 ₽ |
| Проценты | 200 637,88 ₽ |
| Общие выплаты | 1 200 637,88 ₽ |
| Остаток после последнего платежа | 0,00 ₽ |

По первой записи графика: проценты — 20 000 ₽, погашение основного долга — 46 702,10 ₽, остаток — 953 297,90 ₽.

Для проверки нагрузки сравнивается `maximum_payment` с `available_monthly_payment` из [финансовых показателей](FINANCIAL_METRICS.md). У контрольной заявки доступно 70 000 ₽: 18 месяцев проходят проверку, 12 месяцев с платежом 94 559,60 ₽ — превышают лимит. Сравнение выполняется только при успешном расчёте графика и статусе финансовых показателей `calculated`; остальные проверки заявки выполняются отдельно.
