# Подготовка к сдаче

Основание: ТЗ «Умный кредитный кабинет предпринимателя», 16 страниц, и переданные разъяснения организаторов. Ключевые требования к комплекту — стр. 7; ограничения — стр. 10–11; скоринг и решение — стр. 14–15.

## Комплект

В папке `submission/` находится только `links.txt` — текстовый файл со ссылками на репозиторий, фиксированную версию, продуктовый обзор и документацию. Этот файл можно приложить к форме сдачи; при необходимости его можно упаковать в ZIP. Текстовый архив разрешён разъяснением организаторов, поэтому переносить весь Git-репозиторий в ограничение 18 МБ не требуется.

Версия фиксируется тегом `submission-2026-10-25`. Перед дедлайном команда должна сверить его с фактически сдаваемым состоянием: последующие изменения автоматически в тег не входят. Дедлайн в переданных материалах не указан.

## Соответствие требованиям

| Что требуется | Где находится / как проверить |
|---|---|
| Код и история коммитов | GitHub-репозиторий, тег `submission-2026-10-25` |
| Доступ жюри к приватному репозиторию | Приглашение `alfa-hack-2026` отправлено 25.10.2026; аккаунт должен принять его |
| Docker и воспроизводимый запуск | `Dockerfile`, Compose-файлы, `python -m scripts.start_hackathon` |
| Основной путь без модели и платного доступа | `python -m scripts.start_hackathon --without-ai`; ручной сценарий из README |
| Возможность указать свой URL, ключ и модель | `.env.api`, `--env-file`, [инструкция](CLONE_AND_RUN.md#свой-api-или-модель-вне-docker) |
| Источник весов и локальный запуск | [Gemma, SHA-256 и режимы](LLM_MODES.md), [компоненты и лицензии](../THIRD_PARTY_NOTICES.md) |
| Версии языка и библиотек | Digest базовых образов, `uv.lock`, `requirements.txt` с хешами, `frontend/package-lock.json` |

| Архитектура, состояния и модель данных | [Схемы и описание](technical/ARCHITECTURE.md) |
| API, OpenAPI/Swagger и коллекция запросов | `/docs`, `/openapi.json`, [сохранённый OpenAPI](technical/openapi.json), [Postman](../contracts/credit_process.postman_collection.json) |

Все компоненты приложения запускаются в Docker. Локальная модель может работать отдельно — это допускается разъяснением организаторов. API Dahl остаётся стандартным режимом, но его ключ и квота не требуются для проверки основного кредитного пути.

## Перед отправкой

1. Убедиться, что жюри приняло приглашение и видит тег.
2. Открыть ссылки из `submission/links.txt` под доступным жюри аккаунтом.
3. Проверить запуск и основной сценарий из README. Использовать отдельное имя Docker-проекта, чтобы не менять демонстрационный стенд.
4. После публикации VPS добавить его реальный адрес в файл ссылок. При записи демо добавить ссылку на видео. Не заменять эти ссылки локальным `localhost`.

На стр. 7 ТЗ также есть фраза про персонализированную новостную ленту, не согласующаяся с остальным кредитным кейсом. В MVP реализован кредитный конвейер; новостной модуль не заявляется. Если организаторы считают этот пункт обязательным, нужно отдельное уточнение.
